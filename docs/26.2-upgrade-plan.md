# Minecraft 26.2 升级计划

> 状态：**已实施，构建、启动注入与游戏内自动化 tooltip 验证通过；发布待做**
> 目标：为 Minecraft 26.2 提供独立构建与发布
> 基线：`master` 当前支持 Minecraft 1.21.5–1.21.8（v1.3.0）
> 日期：2026-10-21

## 1. 结论

可行，预计工作量约 **1–2 天**，技术风险较低。

Minecraft 26.2 使用 **Java 25 + 未混淆的 Mojang 名称**，与 1.21.x 的 Yarn/intermediary 体系不兼容。因此本分支按**独立发布线**处理：

- 本分支（`26.2-upgrade`）只负责 26.2 适配；
- 发布独立版本（建议 `v2.0.0`）；
- 不在本分支完成前改动 `master` 上的 1.21.x 发布；
- 不尝试用一个 jar 同时支持 1.21.x 与 26.x。

## 4. API 兼容性核对（已用 26.2 jar 实测）

| 当前依赖 | 26.2 对应 | 结论 |
| --- | --- | --- |
| `TooltipDisplayComponent.shouldDisplay` | `TooltipDisplay.shows(DataComponentType<?>)` | ✅ 语义相同，改方法名 |
| `DataComponentTypes.TOOLTIP_DISPLAY` / `ENCHANTMENTS` | `DataComponents.TOOLTIP_DISPLAY` / `ENCHANTMENTS` | ✅ |
| `AttributeModifiersComponent.Display.Hidden` | `ItemAttributeModifiers.Display.hidden()` | ✅ |
| 隐藏属性在 `Display.apply` 前被跳过 | `lambda$addAttributeTooltips$0` 中仍是 `display == Display.hidden() → return` | ✅ 机制未变 |
| `ItemEnchantmentsComponent` | `net.minecraft.world.item.enchantment.ItemEnchantments`（包名变化） | ✅ `isEmpty()` 保留；`getEnchantments()` → `keySet()` |
| `MinecraftClient` | `Minecraft` | ✅ |
| `Options.advancedItemTooltips` | 同名字段保留 | ✅ |
| Fabric `ItemTooltipCallback` | `(ItemStack, Item.TooltipContext, TooltipFlag, List<Component>)` | ✅ 签名结构不变 |
| `Text` / `Formatting` | `Component` / `ChatFormatting` | ✅ |

核心实现思路不变：

1. 在 F3+H 高级提示开启时，让 `TooltipDisplay.shows(...)` 返回 `true`；
2. 在属性 tooltip 路径中，把逐条的 `Display.hidden()` 替换为 `Display.attributeModifiers()`。

## 6. 风险与待确认

1. **Loom 1.18 未混淆工具链较新**：先按官方 `26.2` 模板跑通最小构建，再迁移 mod 代码。
2. **属性隐藏实现依赖 `ItemStack` 内部结构**：26.2 中逻辑仍在，但合成 lambda 名可能变化；优先使用命名方法 `addAttributeTooltips`。
3. **JDK 25**：本机未安装，需先安装并确认 Gradle 9.7.1 能使用。
4. **单 jar 多版本不可行**：Yarn 与 Mojang 名称、Java 21/25 无法共存，发布策略需确认。
5. **CurseForge 版本类型名称**：发布前需确认 `Minecraft 26.2:26.2` 能被上传 action 正确解析。
6. **后续 26.x 小版本**：26.1/26.3 的 API 可能继续变化，先以 26.2 为准。
